# 能吃吗 · 饮食宜忌助手

一个纯前端、数据完全存在手机本地的**多病种饮食宜忌助手**（原名「肾石康复助手」，已完成多病种重构）。

按你勾选的健康状况（肾结石 / 智齿发炎 / 高血压，可多选），对每一份食物自动判定「可吃 / 适量 / 忌口」，多种病症叠加时取最严结论。

## 主要功能

- **多病种饮食判定**：支持肾结石（按草酸钙 / 尿酸等类型细分）、智齿发炎、高血压，多病种合并判定取最严格结果，忌口理由逐条列出。
- **饮食查询 & 今日评分**：输入菜名自动识别其中食材（如「土豆藕炖排骨」），内置 300+ 常见食物与调料，并给当天饮食打分。
- **未收录也能记**：输入库里没有的食物时，可手动选分类和宜忌程度记一笔，自动存入"我的食物"，下次直接命中；搜不到的词还会自动收进"待补充清单"。
- **今日建议**：根据手术日期自动计算"术后第几天"，给出饮水、复查、饮食忌口等建议。
- **用药警示**：高血压+降压药时提示西柚红线等药物饮食冲突（红色醒目提醒）。
- **健康时间线**：症状、饮食、饮水、用药、检查、备注全部带日期+时间记录，不串台。
- **出院记录识别**：拍照或粘贴出院记录文字，本地规则自动提取手术日期、结石类型、患病侧等关键信息，一键填入档案。
- **检查报告**：上传报告图片与关键指标，随时回看。
- **AI 助手（默认关闭）**：接入自己的 OpenAI 兼容 API Key 后可提问，不发送历史对话与图片。
- **数据备份导出/导入**：换手机时可手动迁移。
- **应用内版本显示**：「我的」页底部可查看当前版本，方便确认更新是否生效。

## 隐私说明

**所有数据仅保存在你本机浏览器（localStorage + IndexedDB），不会上传到任何服务器。**

反馈建议会外跳到 GitHub Issues 页面，需要你手动填写，不会自动带出任何本地健康数据。

## 如何使用

1. 手机浏览器打开 Pages 链接。
2. 点击浏览器"添加到主屏幕"，即可像原生 App 一样离线使用（PWA）。
3. 到「我的」填写个人档案（勾选身体状况），开始记录。
