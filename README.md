# 肾石康复助手

一个纯前端、数据完全存在手机本地的肾结石术后康复管理小工具。

## 主要功能

- **今日建议**：根据手术日期自动计算"术后第几天"，给出饮水、复查、饮食忌口等建议。
- **健康时间线**：症状、饮食、饮水、用药、检查、备注全部带日期+时间记录，不串台。
- **饮食查询 & 今日评分**：输入菜名自动识别食材，按结石类型判断"可吃 / 适量 / 忌口"，并给当天饮食打分。
- **出院记录识别**：拍照或粘贴出院记录文字，本地规则自动提取手术日期、结石类型、患病侧等关键信息，一键填入档案。
- **检查报告**：上传报告图片与关键指标，随时回看。
- **AI 助手（默认关闭）**：接入自己的 OpenAI 兼容 API Key 后可提问，不发送历史对话与图片。
- **数据备份导出/导入**：换手机时可手动迁移。

## 隐私说明

**所有数据仅保存在你本机浏览器（localStorage + IndexedDB），不会上传到任何服务器。**

反馈建议会外跳到 GitHub Issues 页面，需要你手动填写，不会自动带出任何本地健康数据。

## 如何使用

1. 手机浏览器打开 Pages 链接。
2. 点击浏览器"添加到主屏幕"，即可像原生 App 一样离线使用（PWA）。
3. 到「我的」填写个人档案，开始记录。
